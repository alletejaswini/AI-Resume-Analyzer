# 🤖 AI Resume Analyzer

An AI-powered web application that analyzes resumes, evaluates ATS compatibility, compares resumes with job descriptions, and provides practical improvement suggestions.

## 📌 Project Overview

AI Resume Analyzer is a Python-based web application designed to help students and entry-level candidates improve their resumes.

The application allows users to upload a resume in **PDF or DOCX format** and automatically analyzes its structure, technical skills, ATS compatibility, and compatibility with a target job description.

It also provides AI-assisted feedback and generates a downloadable professional resume analysis report.

---

## ✨ Features

- 📄 Upload PDF and DOCX resumes
- 🔍 Extract resume text automatically
- 🛠️ Detect technical skills
- 📊 Calculate ATS-oriented resume score
- 📋 Detect important resume sections
- 💼 Compare resume with a job description
- ✅ Identify matching skills
- ⚠️ Identify missing skills
- 🔑 Detect important keywords
- 💡 Generate resume improvement suggestions
- 🤖 AI-powered resume analysis
- 🔄 Built-in fallback analyzer when AI service is unavailable
- 📑 Generate downloadable PDF reports
